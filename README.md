# Itz Fizz — Road Motion & Interactive Stats

One pinned viewport. The welcome phrase is shifted inward from the left curb and sized responsively to keep “FIZZ” visible. The car travels farther across the road and ends near the right edge, reducing the empty gap. Sage-toned stat cards pop in at scroll-linked checkpoints, fade out as the car continues, and have a subtle sheen/hover response.

## Run
```bash
npm install
npm run dev
```
Open http://localhost:3000.
